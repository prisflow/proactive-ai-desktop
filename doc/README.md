# 文档说明

本目录下的材料分为两种，用途不同，不要混写。

## 架构文档

以自然语言为主，把设计动机、模块分工和关键概念讲清楚；**允许使用必要的架构名词**（如主智能体、记忆模块、事件总线、钩子等），但不展开到接口名、文件名或具体代码结构。不画实现级图示。

## 技术实现记录

只记录落地细节，三选一或组合使用：

- 后端：接口形态、入参与出参、错误与边界。
- 前端：数据如何流动（可用 Mermaid 画管线图）。
- 前端界面：组件与职责，用表格罗列。

实现记录里可以使用工程用语；与架构文档分开维护，避免架构稿被实现细节带跑。

## 当前文件

- `架构-主动对话与统筹.md`：主动对话与多帮手统筹的总体架构（架构文档）。
- `技术实现-智能体编排.md`：事件信封、IPC、`agent:push`、钩子点、插件 bridge、子智能体与双记忆顺序（技术实现记录）。
